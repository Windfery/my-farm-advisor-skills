# Grower Web Map Provenance

## Origin

- Created 2026-11-12 in this repository on branch `grower-web-map` for Assignment 1.
- No third-party source code is vendored. The generator is original standard-library
  Python written against the existing runtime contract.
- The map renders in the browser with **Leaflet 1.9.4**, loaded from jsDelivr and
  pinned in the HTML rather than copied into the repository.

## Data sources

| Layer | Source | Terms and notes |
| --- | --- | --- |
| Field polygons | Pipeline output from OpenStreetMap via Overpass, written to `boundary/field_boundaries.geojson` | ODbL 1.0; retain OpenStreetMap attribution |
| Farm, grower, field names | Runtime `farm.json`, `grower.json`, `fields/<slug>/field.json` | Generated by the data pipeline |
| Area | Boundary property `area_acres` | Converted to hectares; original value is not redistributed |
| Basemap | Esri World Imagery (`server.arcgisonline.com`) | © Esri, Maxar, Earthstar Geographics, and the GIS User Community; attribution rendered in the map |
| Labels | Esri World Boundaries and Places reference tiles | © Esri; optional overlay |
| Street fallback | OpenStreetMap standard tiles | © OpenStreetMap contributors, ODbL |

## Coordinate and measurement decisions

- Geometry is embedded exactly as the pipeline wrote it, in EPSG:4326 (lon/lat). No
  reprojection or simplification is applied, so the viewer matches the boundary file.
- Hectares are derived from the reported acres with the exact international acre
  (`4046.8564224 m²`). The alternating source, used only when a feature has no
  `area_acres`, is a spherical polygon area over the authalic Earth radius; it is a
  fallback, not a re-survey.

## Runtime and repository boundary

- Generated HTML and manifests are runtime artifacts under
  `${DATA_PIPELINE_DATA_ROOT}/data-pipeline/growers/<grower>/derived/maps/` and are
  never committed.
- `examples/` documents regeneration only; no generated map is checked in because the
  page depends on live runtime grower data and online tiles.
